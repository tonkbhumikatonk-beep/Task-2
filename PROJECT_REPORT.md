# PROJECT REPORT
## Credit Card Fraud Detection Using Machine Learning

### 1. Introduction
Credit card fraud detection is a classification problem in which a machine-learning model learns patterns from transaction data and predicts whether a new transaction is genuine or fraudulent.

### 2. Objective
The objective is to build a supervised machine-learning model that classifies transactions into two classes:
- Genuine (0)
- Fraudulent (1)

### 3. Project Requirements Mapping
This project follows the Project 2 requirements:
1. Load and understand a dataset.
2. Split the data into training and testing sets.
3. Apply a classification algorithm.
4. Train and evaluate the model.

### 4. Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Joblib

### 5. Dataset
A synthetic dataset of 10,000 transactions is generated by the project itself. It contains transaction amount, time, distance, online/international status, merchant risk, card presence, transaction velocity, account age, and the fraud target.

### 6. Data Preprocessing
The data is loaded using Pandas. Missing values and class distribution are checked. The target column `fraud` is separated from the input features. A stratified 80:20 train/test split is used so the fraud ratio is approximately preserved.

### 7. Machine Learning Algorithms
#### Logistic Regression
Used as a simple baseline classification model.

#### Random Forest
Used as the main classifier. It combines many decision trees and is suitable for nonlinear patterns in tabular transaction data. Class weighting is used because fraud is the minority class.

### 8. Model Evaluation
The project reports:
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion matrix

For fraud detection, recall and precision are especially important because missing a fraudulent transaction and incorrectly flagging a genuine transaction have different consequences.

### 9. Workflow
Dataset Generation → Data Loading → Data Inspection → Train/Test Split → Model Training → Prediction → Evaluation → Saved Model

### 10. Expected Output
After running `train.py`, the project creates a trained Random Forest model and evaluation reports/plots in the `models` and `reports` folders.

### 11. Limitations
The dataset is synthetic and is intended for education. Real fraud detection requires real transaction histories, careful privacy controls, concept-drift monitoring, threshold tuning, and production validation.

### 12. Conclusion
The project demonstrates an end-to-end supervised classification pipeline for credit card fraud detection. It satisfies the core Project 2 learning goals while providing a practical AI use case.
